# Lanes test map

Three-lane test map (`/Game/Selene/Maps/Lanes`) for trying heroes against minions. Built 2026-11-13.

- **Layout source:** `layout.json`, generated by `Tools/Maps/lanes_layout.py` (also writes `layout.svg`). The diagram's y axis maps to Unreal -Y.
- **Map builder:** `Tools/Unreal/lanes_build.py`, run with `bash Tools/Unreal/lanes_run.sh python <label> lanes_build`. It rebuilds everything in the `Lanes` outliner folder.
- **Run:** open the project on `/Game/Selene/Maps/Lanes -game`, or `bash Tools/Unreal/lanes_run.sh game <label> <seconds> "<console commands>"`.
- **Game code:** `Source/Selene/Lanes/SeleneLaneDirector.*` (waves, structures, combat, hero hits). Wave settings are `Config` properties of `SeleneLaneDirector` (`[/Script/Selene.SeleneLaneDirector]` in `DefaultGame.ini`).
- **Minimap:** `Source/Selene/UI/SSeleneMinimap.*`, bottom right on any map with lanes. `selene.Minimap 0|1`, `selene.MinimapWidth N`.
- **Console:** `selene.LaneWaves 0|1`, `selene.LaneStress N`, `selene.LaneLog N`, `selene.LaneHealthBars 0|1`, `selene.LaneTour N`, `selene.LaneFastRender 0|1` (read at map start; add it to `DefaultEngine.ini` `[ConsoleVariables]` to change).

## Frame rate (M3 Max, 1600x900 window, 2026-11-13)

- Project default rendering (Lumen GI and reflections): 31-38 fps on this map, and 44 fps on the near-empty MovementTest map. GPU time about 25 ms, of which Lumen is about 10 ms.
- With the map's fast-render preset (Lumen off, time of day held): 59-72 fps average with 50-60 minions fighting, with single frames dipping to 20-30 fps.
- Minion logic costs about 0.5 ms a frame.
- Minimap on: 66-68 fps average with 40-52 minions; off: 69-72 fps (same session, after stopping a stuck CrashReportClient that had been using a full core and caused most of the earlier dips).

## Known gaps

- Building fronts are not checked: some face the street with a side wall.
- Minions do not attack the hero; the hero has no health.
- No effects, sounds or projectiles. Ranged damage is instant.
- Equal waves stalemate at the lane centre unless the hero tips a lane.
